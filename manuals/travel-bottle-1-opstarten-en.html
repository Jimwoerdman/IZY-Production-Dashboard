Starting the travel bottle printer

How to switch on the UV cylinder printer for travel bottles (Suntech C360-CF3) and get it ready to print. Follow the steps in this order.

You need: non-dust cloth (lint-free) · PC code: 1997 · Time: approx. 5–10 min

The machine

  • Siemens touchscreen, with the UV Lamp, Lighting Lamp and Vacuum lights below it, plus the Press Ink and Print start buttons.
  • Start / Stop buttons next to the machine door.
  • The 4 print heads are behind the door.
  • The computer with the PrintExp X64 print software is next to the machine.
1

Switch on the machine and computer

  1. When you arrive, press the green START button on the machine straight away.
  2. Switch on the computer.
Warning: does the power trip?

Sometimes the circuit breaker (the "stopper") trips when you switch on. If so:

  1. Go to the door behind the machine. The fuse box is there.
  2. Push the switch that has dropped down back up.
  3. Go back and continue with step 1.

Nothing tripped? Just continue with step 2.

2

Log in to the computer

  1. Log in with code 1997.
  2. Let the computer start up. Meanwhile, continue with step 3.
3

Set up the Siemens screen

While the computer starts up, go to the Siemens touchscreen on the machine.

  1. Tap System Login.
  2. Tap Select manual (yellow box, ①).
  3. Tap Alarm elimination (②). The red square turns green.
4

Purge the print heads

  1. Open the machine door. You can now see the 4 print heads.
  2. Hold the Press Ink button down for 5 seconds.
  3. Watch the print heads meanwhile: only let go when ink drips down from all 4 heads.
5

Wipe the print heads clean

  1. Take a non-dust cloth (lint-free).
  2. Fold the cloth neatly.
  3. Wipe the print heads from back to front. One direction only, starting at the back each time.
✓ Non-dust cloth, neatly folded
✗ No wet cloth or wet wipe
✓ Only from back to front
✗ Do not wipe back and forth
6

Open the print software

  1. The computer has now started. Open PrintExp X64 using the icon on the desktop.
  2. No error messages? Then the printer is ready and you can start printing.

✓ Ready to print.

Checklist

All checked. The printer is ready.
