Printing travel bottles

How to operate the travel bottle printer and print an order. Do part 1: starting the printer first. The machine and PrintExp must be on.

You need: print dashboard (Microsoft Edge) · the blank bottles for the order · Print time: approx. 2 min per bottle

1

Check the print head temperature

  1. In PrintExp, go to the Voltage tab.
  2. Click Refresh at the bottom right.
  3. Check the Head Temp row: all heads must be at least 43 °C.
Below 43 °C?

Do not print yet. Wait a moment and click Refresh again.

2

Pick the order in the print dashboard

  1. Open the print dashboard in Microsoft Edge.
  2. Go to the Travel Bottles section. Only those orders go on this machine.
  3. Pick the top order.
  4. Copy the Print Name of that order.
  5. Note the Qty (number of bottles). You need it in step 4.
3

Open the print file in PrintExp

  1. Go back to PrintExp and click OpenFiles.
  2. Paste the Print Name into the search field.
  3. Open the file. It appears on the left in the Print job list.
4

Set the number of bottles

  1. Right-click the file you just opened.
  2. Choose Task Setting.
  3. In Count, enter the number of bottles plus 5% or plus 5 bottles.
  4. Click OK.
Example

The order is 150 bottles, so you enter 155.

5

Load the bottle into the machine

  1. Take a bottle. Place your index finger on the bottle, in line with the middle of the screw thread.
  2. Place the bottle in the holder with the opening to the right.
  3. Turn the bottle so your finger points straight up.
  4. Then turn the bottle back a little (about 10%).
6

Print

  1. Go back to the computer. Right-click the file again and choose Print. The job is now ready.
  2. On the machine, press the green Print start button.
  3. The machine prints the bottle. Wait about 2 minutes until the bottle is done.

✓ Bottle done. Take it out, load the next bottle (step 5) and press Print start again.

Checklist

All checked. The order is running.
