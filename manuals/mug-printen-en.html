Printing mugs

How to get the mug printer (Mug 1) ready and print an order. Do part 1 first: starting the printer. Note: the preparation on the Siemens screen differs from the bottle printers.

1

Home the clamping shaft

  1. On the Siemens screen, tap System Login.
  2. Tap Debug and go to Clamping shaft.
  3. Press Inching Clamping until Origin turns green.
2

Raise the lifting axis

  1. Go to Lifting Axis.
  2. Press Jog Up briefly, really only 1–2 seconds.
  3. Check that Origin and Positive limit are green.
3

Reset the machine

  1. Go to Main Control.
  2. Hold Reset for 5 seconds.
  3. An orange bar appears and the machine moves.
  4. The red indicator switches to green: Device is Ready. Then it is ready.
4

Save the positions

  1. Go back to Debug → Clamping shaft and press Save Position.
  2. Go to Lifting Axis and also press Save Position.
  3. The machine is now in the right position to load a mug.
5

Choose: manual or automatic

Manual

Leave the button on the Siemens screen yellow. Tick Manual in the print software.

Automatic

Press the yellow button so everything turns green. Untick Manual in the print software.

6

Set up the print file

  1. Pick the right print file in the print software.
  2. Click Modify, set C and W and click Apply.
  3. Enter the number of mugs to print in Print Quantity.
7

Start printing

  1. Click the Print button, then Yes.
8

Load the mug and START

For automatic printing:

  1. Place the mug in the printer with your finger on the screw thread.
  2. Find the right position yourself, so the cap ends up at the front.
  3. Press the green START button on the machine. The mug is printed.

Checklist

All checked. The mugs are printing.
